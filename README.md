# Harding Labs: Landing Page

The marketing site for **Harding Labs**, an independent AI product studio. It introduces the studio, showcases the live products ([StageSnap](https://stagesnap.xyz) and [Vibecation](https://vibecation.xyz)), and links to the founder's portfolio.

**Live:** [hardinglabs.io](https://hardinglabs.io)

## Highlights

- Animated hero with SVG circuit traces and a branded loading animation
- Interactive before/after slider for StageSnap's AI staging results
- Scroll-reveal sections for the work, studio principles, and contact
- Fully static and responsive, with no client-side data fetching

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Vercel

## Run it

```bash
npm install
npm run dev     # http://localhost:3000
```

## Layout

```text
src/app/          page, layout, global styles and icons
src/components/   BeforeAfterSlider, CircuitTraces, LoadingAnimation, Reveal
docs/             design notes
```
